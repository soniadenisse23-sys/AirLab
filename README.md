1. Descripción del proyecto
AIRLAB es una estación modular portátil diseñada para estudiar y controlar variables físicas relacionadas con el flujo de aire, como velocidad, temperatura, presión diferencial y caudal.
2. Objetivos
- Medir variables del flujo de aire.
- Controlar la velocidad del ventilador.
- Regular la temperatura mediante un sistema de calentamiento.
- Visualizar los datos mediante una interfaz desarrollada en Python.
3. Componentes
- Arduino Mega 2560.
- Sensor de temperatura MAX6675.
- Sensor diferencial SDP31.
- Ventilador industrial.
- Pantalla LCD.
- Interfaz gráfica en Python.
